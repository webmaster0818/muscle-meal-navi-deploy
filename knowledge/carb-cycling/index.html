筋トレにおける炭水化物の正しい摂り方

炭水化物は筋トレの最重要エネルギー源。トレーニング日と休息日で摂取量を変える 「カーブサイクリング」を取り入れれば、筋肉を維持しながら効率的に体脂肪を落とせます。

なぜ筋トレに炭水化物が必要なのか

筋グリコーゲンの補充

高強度トレーニングのエネルギー源の約80%は筋グリコーゲン（炭水化物由来）。不足するとパフォーマンスが大幅に低下します。

筋分解の防止

炭水化物が不足すると、体はアミノ酸（筋肉）からエネルギーを作ろうとします。筋肉を守るために炭水化物は必須です。

インスリンの活用

炭水化物摂取で分泌されるインスリンは、アミノ酸を筋肉に取り込む「輸送役」。トレ後の筋合成を促進します。

カーブサイクリングとは

カーブサイクリング（Carb Cycling）は、日によって炭水化物の摂取量を変える食事戦略です。 トレーニング日は炭水化物を多く摂り、休息日は少なくすることで、筋肉のパフォーマンスを維持しながら体脂肪を効率的に減らすことができます。

摂取量の目安（体重1kgあたり）

日タイプ炭水化物量タイミング例（70kg）
High Day体重×5〜7g高強度トレ日（脚・背中など）350〜490g
Mid Day体重×3〜4g中強度トレ日（肩・腕など）210〜280g
Low Day体重×1.5〜2.5g休息日・有酸素のみの日105〜175g

GI値で炭水化物を使い分ける

GI値（グリセミック・インデックス）は血糖値の上昇スピードを示す指標。普段は低GIで血糖値を安定させ、トレ後は高GIで素早くグリコーゲンを補充するのが理想です。

1週間のカーブサイクリングモデルプラン

体重70kgの場合の目安です。自分の体重に合わせて調整してください。

月曜（胸・三頭）High体重×6g（70kgなら420g）

朝オートミール80g / 昼白米200g / トレ前バナナ1本 / トレ後白米250g+鶏胸肉 / 夜玄米150g

火曜（背中・二頭）High体重×6g（70kgなら420g）

朝オートミール80g / 昼パスタ100g / トレ前さつまいも150g / トレ後白米250g / 夜玄米150g

水曜（休息日）Low体重×2g（70kgなら140g）

朝オートミール40g / 昼玄米100g / 夜さつまいも100g / 間食はたんぱく質中心

木曜（肩・腕）Mid体重×4g（70kgなら280g）

朝オートミール60g / 昼白米150g / トレ前バナナ1本 / トレ後白米200g / 夜そば1束

金曜（脚）High体重×7g（70kgなら490g）

朝オートミール80g / 昼白米250g / トレ前もち2個 / トレ後白米300g / 夜パスタ100g

土曜（休息日）Low体重×2g（70kgなら140g）

朝オートミール40g / 昼そば1束 / 夜玄米100g / 間食はナッツ・プロテイン

日曜（休息日）Mid体重×3g（70kgなら210g）

朝オートミール50g / 昼玄米150g / 夜さつまいも150g / 翌日のトレに備える

宅配弁当との組み合わせ方

High Day（トレーニング日）

宅配弁当＋白米を大盛りで追加。マッスルデリの GAINコースは炭水化物も多めに設計されているのでそのままでもOK。

Low Day（休息日）

宅配弁当のみで完結。noshは 糖質30g以下に設計されているのでLow Dayに最適。ご飯の追加は不要です。

よくある質問

炭水化物を完全にカットしたほうが痩せますか？
いいえ。炭水化物は筋トレのエネルギー源であり、完全カットはパフォーマンス低下・筋肉分解を招きます。減量期でも体重×2g以上は確保しましょう。
カーブサイクリングは初心者でもできますか？
はい。まずはトレーニング日を「多め」、休息日を「少なめ」の2段階から始めるのがおすすめです。慣れてきたらHigh/Mid/Lowの3段階に調整しましょう。
トレーニング後は何分以内に炭水化物を摂るべき？
トレ後30分〜2時間以内が理想です。この「ゴールデンタイム」にたんぱく質と一緒に高GI炭水化物を摂ると、グリコーゲン補充と筋合成が促進されます。
GI値が高い食品は避けるべき？
場面によります。普段の食事では低GI食品を選びましょう。ただしトレーニング直後は高GI食品（白米、もち、バナナ等）のほうがグリコーゲン補充に有利です。
宅配弁当でカーブサイクリングはできますか？
可能です。Low日は宅配弁当のみ、High日は宅配弁当＋白米を追加するなどの調整で実現できます。PFCが明記されたマッスルデリやnoshが管理しやすくおすすめです。
脂質と炭水化物はどちらを減らすべき？
筋トレをしている方は炭水化物を確保し、脂質を適度に抑えるのが基本です。ただし脂質も体重×0.8g以下にはしないようにしましょう。ホルモンバランスに影響します。
